# AP Assignment Repository

This repository contains all assignments completed as part of the Advanced Programming (AP) coursework.

## Repository Structure

Each assignment is maintained in a separate branch:

* assignment1
* assignment2
* assignment3
* ...
* assignment19

The `main` branch serves as the central repository and branch index, while the actual assignment implementations are stored in their respective branches.

## How to Access an Assignment

To view a specific assignment:

```bash
git checkout assignment<number>
```

Example:

```bash
git checkout assignment19
```

## Technologies Used

Assignments may include programs written in:

* C
* C++
* Java
* Python
* Bash Scripting

depending on the requirements of the individual assignment.
